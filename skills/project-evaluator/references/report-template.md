# 报告模板（Step 3）

直接按以下结构输出，保留标题层级与表格。方括号内容为填充说明，输出时删除。
全文控制在 800 字以内；能用表格说清的不写成段落。

---

## 📋 项目评估报告：[项目名称]

**评估时间**：[YYYY-MM-DD]｜**信息完整度**：[6/6 ｜ 4/6 等]

### 一、执行摘要

[2-3 句话。第一句说清这是个什么项目；第二句说最大的机会或亮点；第三句说最大的坎。不含术语。]

### 二、总体可行性评分

**[X.X] / 10**　[一句话解读，例如「方向没问题，主要卡在时间上」。若未知槽位 ≥ 3，此处追加「（信息不足，仅供参考）」]

[分两层写，评级取两者中较弱的一档：]
